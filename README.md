# Premanand Nagarajan — Senior Azure Data Engineer Portfolio

A responsive, static personal portfolio website built with HTML, CSS, and vanilla JavaScript. No build tools, package installs, or paid hosting are required.

## Preview locally

Open `index.html` in a web browser. All website files must stay together in the same folder.

## Publish using GitHub Pages

1. Sign in to https://github.com and create a public repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your actual GitHub username). Alternatively, use a regular repository name for a project-site URL.
2. Upload `index.html`, `styles.css`, and `script.js` to the **root** of the repository. You may also upload this README.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. Wait for GitHub Pages to deploy. Visit `https://YOUR_USERNAME.github.io/`. For a regular repository, the URL is usually `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`.
6. In your GitHub repository, optionally set the website URL in the **About** section.

Official guide: https://docs.github.com/en/pages/quickstart

## Add your link to LinkedIn and resume

- LinkedIn: Edit your profile's **Contact info** and add your website. Also add the link to **Featured** if available.
- Resume header: `Portfolio: https://YOUR_USERNAME.github.io/`
- LinkedIn headline or About section: Mention your portfolio naturally; avoid inserting long URLs into the headline.

## Customize before publishing

- Confirm your location, dates, job titles, and contact information.
- The **Projects** section currently contains *representative, high-level case studies*, not public code repositories. Add original demo repos using synthetic or licensed public data before claiming runnable examples.
- Add certifications only after verifying the credentials. This starter does not assert any certifications.
- Optionally add a downloadable resume PDF after removing sensitive personal information; add a button in `index.html` linking to the PDF.
- Keep company data, customer data, credentials, internal URLs, and proprietary code out of the public repository.
